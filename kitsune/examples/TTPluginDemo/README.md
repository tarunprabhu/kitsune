# Sample Tapir Target Plugin

[`TTPluginDemo.cpp`](TTPluginDemo.cpp) contains a sample tapir target plugin
intended to be loaded from a dynamic shared object. For more information about
writing and building tapir target plugins outside Kitsune, consult the
[documentation](../../docs/WritingTapirTargetPlugin.md), in particular for
details about how to build the plugin outside Kitsune.
