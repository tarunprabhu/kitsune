# Language Extensions

Kitsune relies on extensions to the source languages to determine which loops
can be parallelized. It currently does not, and likely will never, perform any
analysis to determine this automatically. Kitsune provides extensions to the
supported languages that the programmer must use to expose such loops to the
tapir targets. These extensions are described here.
