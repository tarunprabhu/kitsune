# LLVM Intrinsic Reference

These are Kitsune-specific intrinsic functions that have been added to LLVM.
These are nearly always added by a [tapir target](glossary-tapir-target), but
may also be added by Kitsune's drivers. In most cases, these are lowered to a
call to one of Kitsune's runtime functions.
