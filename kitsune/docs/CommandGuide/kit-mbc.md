# kit-mbc - Extract embedded bitcode from an LLVM-IR module

## Synopsis

**kit-mbc** [_options_] [_input_]

## Description

Extract embedded bitcode from an LLVM-IR module.

## Options

**-f**

: Force binary output on terminals.

**--help**

: Print a summary of **kit-mbc** command-line options.

**-o** <file>

: Write the extracted bitcode to the given file.

**--tapir**={ {{kitsune_known_tapir_targets_alternatives}} }

: Extract only the embedded bitcode generated by this tapir target.

**-S**

: Write output as LLVM assembly

**--version**

: Print the version of this program.

## Exit Status

If an error occurs, `kit-mbc` exits with a non-zero value. Otherwise, exit
with 0 to indicate success.

## Examples

The module from which to extract bitcode can also be piped into **kit-mbc**.

```
cat in.bc | kit-mbc
```

By default, the extracted bitcode will be written to stdout. If stdout is a
terminal i.e. it has not been redirected to a file, only a warning message will
be printed.

```
kit-mbc in.bc
WARNING: You're attempting to print out a bitcode file.
This is inadvisable as it may cause display problems. If
you REALLY want to taste LLVM bitcode first-hand, you
can force output with the `-f' option.
```

Since writing binary output to the terminal is inadvisable, the `-S` option can
be used to write human-readable assembly to the terminal.

```
kit-mbc -S in.bc
```

Alternatively, stdout can be redirected to a file.

```
kit-mbc in.bc > extracted.bc
```

If a tapir target is explicitly specified and the input module does not contain
embedded bitcode generated by that tapir target, nothing will be written to
stdout.

```
./bin/kit-mbc --tapir-target=hip in.bc
warning: No embedded bitcode modules found
```
