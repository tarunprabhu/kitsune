# Tools Reference

The pages listed here describe Kitsune-specific tools and utilities, how to
use them, and their command-line options. They
_do not_ describe all the options for all the tools. To get a complete listing,
pass the `--help` (for general options) or `--help-hidden` (for general and
debugging options) command-line options to the tool of interest.

```{note}
All of [LLVM's tools](https://llvm.org/docs/CommandGuide/index.html) are also
available when Kitsune is built and installed,
```
