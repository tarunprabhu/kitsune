# kit-enc - Embed bitcode into an empty host module

## Synopsis

**kit-enc** [_options_] [_input_]

## Description

Embed an LLVM-IR module into an empty [host module](glossary-host-module).
The resulting host module will be printed to stdout as human-readable LLVM
assembly.

## Options

**--help**

: Print a summary of **kit-enc** command-line options.

**--tapir**={ cuda | hip }

: The [tapir target](glossary-tapir-target) to attach to the embedded bitcode.
  This will make it seem as if the [embedded bitcode](glossary-embedded-bitcode)
  was generated by this tapir target. The tapir target specified here must be
  one that generates embedded bitcode.

**--version**

: Print the version of this program.

## Exit Status

If an error occurs, `kit-enc` exits with a non-zero value. Otherwise, exit
with 0 to indicate success.

## Examples

Embed `in.bc` into an empty host module. The result will seem to have been
generated by the [cuda](tapir-targets-cuda) tapir target. In other words, if
the `--tapir` option is not provided, the default is assumed to be
`--tapir=cuda`.

```shell
kit-enc in.bc
```

The input module can also be piped into **kit-enc**. In the example below, the
resulting host module will seem to have been generated by the
[hip](tapir-targets-hip) tapir target.

```shell
cat in.bc | kit-enc --tapir=hip
```

A "minimal" host module containing embedded bitcode can be generated by using
an empty string as the module to embed.

```shell
echo "" | kit-enc --tapir=hip
```
