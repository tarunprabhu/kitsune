# kit-enc - Embed LLVM bitcode into an empty "host" LLVM-IR module

## Synopsis

**kit-enc** [_options_] [_input_]

## Description

Embed an input LLVM-IR module into an empty "host" module. The resulting host
module will be printed to stdout as human-readable LLVM assembly.

## Options

**--help**

: Print a summary of **kit-enc** command-line options.

**--tapir**={ {{kitsune_known_tapir_targets_alternatives}} }

: The tapir target to attach to the embedded bitcode. The resulting module will
  appear seem to have been generated by this tapir target.

**--version**

: Print the version of this program.

## Exit Status

If an error occurs, `kit-enc` exits with a non-zero value. Otherwise, exit
with 0 to indicate success.

## Examples

Embed `in.bc` into an empty host module. The result will seem to have been
generated by the [cuda](tapir-targets-cuda) tapir target. In other words, if
the `--tapir` option is not provided, the default is assumed to be
`--tapir=cuda`.

```
kit-enc in.bc
```

The input module can also be piped into **kit-enc**. In the example below, the
resulting host module will seem to have been generated by the
[hip](tapir-targets-hip) tapir target.

```
cat in.bc | kit-enc --tapir=hip
```
