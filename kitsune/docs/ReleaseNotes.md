# Release Notes #

Kitsune is under very active development. To date, there have been no official
releases. We have prepared [release notes in the past](OldReleaseNotes.md)
when merging with new LLVM releases[^1], but have not done so for some time.
We may resume this practice in the future.

[^1]: LLVM follows a six-month release cycle. We try to merge within a few weeks
of each major release. We generally do not merge with point or bugfix releases
unless they contain changes that are critical for us.
